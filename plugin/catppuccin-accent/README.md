# Catppuccin Accent

Context-aware dynamic flavor and accent color switcher for Catppuccin themes in BetterGravity.

## Features

- **Four Authentic Flavors**: Seamlessly toggle between Mocha (Dark), Macchiato (Mid), Frappé (Muted), and Latte (Light).
- **Fourteen Accent Colors**: Switch between 14 official Catppuccin accent tokens (Rosewater, Flamingo, Pink, Mauve, Red, Maroon, Peach, Yellow, Green, Teal, Sky, Sapphire, Blue, and Lavender) with color-matched glows.
- **Context-Aware Lifecycle**: Automatically mounts the palette trigger button on the title bar only when a Catppuccin theme is active, and unmounts cleanly when switching to other themes.
- **Zero-Reload CSS Token Injection**: Dynamically updates CSS custom properties in real-time with zero UI flickering, and persists user choices durably across restarts.
